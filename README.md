# Public Knowledge Archive Pages (`git-pages-repo`)

- **정문(Front Door)**: `#04 ArchiveOS Virtual Desktop` (4단계 계층 Finder 컬럼 탐색기 + 바탕화면 폴더 + macOS Dock)
- **내부 학습 뷰(Inner Content View)**: `4단계 트리 위키 (AI -> 컨퍼런스 -> 컨퍼런스 이름 -> 세부 정보)` + 빈칸 추론 학습(Cloze) + 블로거/티스토리 HTML & 동영상 생성 JSON 스튜디오
- **프라이버시 게이트키퍼**: `publish_pages: true`로 승인된 요약 문서만 포함되며, 개인 파일 및 미정립 아이디어(`publish_pages: false`)는 빌드에서 원천 제외됩니다.
